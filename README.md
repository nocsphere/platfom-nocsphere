# Nocspehere: development platform for [PlatformIO](https://platformio.org)

# Usage

1. Install [PlatformIO](https://platformio.org) in [VS Code](https://code.visualstudio.com/)

2. Dowload the [blinky](https://github.com/nocsphere/project-nocsphere-empty.git) project

3. Open the project with VS Code

4. Compile the project
